## 📋 Sobre o projeto

Este projeto foi desenvolvido utilizando **PHP** com a arquitetura **MVC (Model-View-Controller)**.

O objetivo é criar uma aplicação organizada, permitindo separar as responsabilidades do sistema em diferentes camadas.

### 🎯 Objetivos

- Organizar o código utilizando MVC
- Trabalhar com PHP
- Utilizar banco de dados MySQL
- Implementar operações CRUD
- Utilizar DAO para acesso aos dados
- Criar uma interface web
- Praticar desenvolvimento backend
